# CataLift Homebrew tap

```sh
brew install catalift/tap/gaslight
```

| Formula | What it is |
|---|---|
| [`gaslight`](Formula/gaslight.rb) | An AI-native fork of Terraform that responds identically to every command. Satire — see [gaslightai.dev](https://gaslightai.dev) and [CataLift/gaslight-cli](https://github.com/CataLift/gaslight-cli). |

Maintained by [CataLift](https://github.com/CataLift), an infrastructure
consultancy.

## Updating a formula

Releases are cut in the source repository. Its release workflow prints the
`url` and `sha256` to paste in here — no build step happens in this repo.
